# 路径规划最终验证报告

本轮对预先冻结的 50 张新合成地图进行验证。11 种随机优化器各运行 30 次，共 16,500 次算法运行；每次种群为 50，目标函数评价预算为 50,050 次，地图与运行序号对应的随机种子在各算法之间一致。路径使用十个二维中间路点，搜索维度为 20。

与 PSA 的成功率差，经地图按五类结构分层重采样得到的近似 95% 区间为 [18.73, 25.00] 个百分点；更保守的十对比较尾部分位敏感性区间为 [17.33, 26.40]。这些是限定于本组合成生成规则的近似重采样结果，不是任意真实地图上的保证。逐图配对可行性检验另以 500 次比较作 Holm 校正，详见分析 CSV。

本轮记录的算法运行错误和警告均为零。NDO 有 11 次无效候选评价，按所有算法共用的保护规则处理并保留在诊断数据中；没有因此删去运行。并行搜索耗时已记录，不能将其视为严格的串行速度测试。

本次保留优化器搜索源码，修改共享评价：可行路径取长度 L；碰撞路径取 B(1+C/T)+L，其中 C/T 是占据栅格访问占比，B=(q+1)D+1 来自几何长度上界。可行路径长度小于 B，碰撞路径评价大于 B，因此没有放宽可行性定义，也没有改变可行解之间的长度目标。该公式是本次实验采用的适配方案，不能称作某篇论文公式的完全复现。原编码仍取整；本次未采用另行试验的连续路点方案。

原来单改地图的试验及其负面结果均保留。最终验证来自开发过的合成结构规则，布局和运行种子提前固定；结构之间仍存在相似性。不能把全部提升仅归于地图，也不能由这 50 张图推断对任意地图、动态环境或真实机器人都有效。A* 是单独列出的确定性参考，不参与 11 种随机优化器排名。

针对路径规划相关审稿意见：提供障碍地图与 ENRBO/NRBO 并排结果；提供同一路径平滑前、一次平滑、两次平滑的对照；分别报告原始与平滑后指标；提供多结构、多尺寸、30 次运行的完整结果与配对统计。上述证据回应相应实验问题，不等同于保证所有审稿意见都已解决。
