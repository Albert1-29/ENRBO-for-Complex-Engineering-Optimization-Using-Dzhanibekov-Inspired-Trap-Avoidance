Frozen prospective validation protocol, 2026-10-30.
The merit function and all optimizer source files were frozen after developer trials on previously used maps. The validation comprises all 50 newly generated layouts (10 per synthetic family) from geometry seeds 51100101 onward, with new paired trial seeds based at 37261030. No maps will be selected or removed based on algorithm outcomes.
Population 50; common counted objective budget 50050 per optimizer call; 30 runs per map and algorithm; 11 unmodified stochastic optimizers. Empty paths, invalid evaluations, failures and runtime errors must remain in the outputs.
Primary endpoint: raw-path feasibility. Secondary endpoint: feasible-first paired ranks using raw path length. The existing postprocessing ranks and before/after smoothing are reported separately. Do not interpret improvement in postprocessed ranks as raw feasibility improvement. A* is an additional deterministic reference and is not included among the 11 metaheuristics in the aggregate ranks.
Shared merit: J=L for feasible paths; otherwise J=B*(1+C/T)+L, B=(q+1)*D+1. C is the number of occupied supercover cell visits and T the number of all visits, counting path traversal per segment, q=10 waypoints and D the map diagonal. The bound makes every feasible path rank above every colliding path. This relative exposure heuristic is an experimental design, not an exact reproduction of a published formula or a feasibility guarantee.
The generator families were chosen and developed using earlier results. This new-layout and new-seed validation is conditional on those synthetic generators; it cannot establish real-world or arbitrary-map superiority. Geometry resemblance and the limited scenario range must be disclosed. Preserve all earlier exploratory and holdout results, including negative results.
All algorithms share waypoint encoding, decoding, collision rules, smoothing and scoring. Optimizer equations and DF remain unchanged.
